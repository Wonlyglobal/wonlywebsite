يحدد طلب التسعير المفيد نطاق التوريد والمعلومات المؤكدة والمسؤول عن الأسئلة المفتوحة. صورة من الكتالوج وعدد الأبواب لا يكفيان لتعريف مجموعة باب قابلة للتصنيع. ابدأ بجدول فتحات منسق.

## سطر مستقل لكل رمز باب

سجّل الموقع والكمية وعرض الفتحة النهائية وارتفاعها ومادة الجدار وسماكته ومنسوب الأرضية النهائية واتجاه الفتح وعرض المرور المطلوب. وضّح الوحدات وميّز القياسات الميدانية عن الأبعاد التصميمية المؤقتة.

يمكن أن تتضمن البطاقة: الرمز / الكمية / الفتحة / الجدار / رسم اتجاه الفتح / مجموعة العتاد / التشطيب / الإثباتات / المعلومة الناقصة / المسؤول / الموعد. لا تستبدل التركيبات المختلفة بمقاس متوسط واحد.

## رسومات تحسم الواجهات

- **الواجهة:** الضلف والإطار والزجاج أو الفتحات الأخرى وحركة الباب.
- **مقاطع الرأس والجوانب والعتبة:** الجدار الداعم وموقع الإطار وعلاقته بالأرضية.
- **العتاد:** القفل والمفصلات والغالق وواجهات التحكم بالدخول ومسؤولية تمديد الكابلات.
- **التشطيب:** عينة معتمدة أو مرجع مضبوط مع ظروف التعرض.

هذه الوثائق للتنسيق وليست بديلاً لتعليمات التركيب. لا تفترض تباعداً عاماً للمثبتات أو خلوصاً موحداً دون اعتماد البناء المختار.

## إثبات لكل متطلب

افصل متطلبات الأمان والحريق والعزل الصوتي. اسأل عن التكوين المقترح الذي تدعمه الوثائق وعن الاختلافات التي تحتاج إلى مراجعة. تقرير لمقاس أو جدار أو عتاد مختلف لا يثبت ملاءمة الطلب تلقائياً. يجب أن يؤكد المصمم المسؤول والجهة المختصة قبول الحل للمشروع.

## مقارنة العروض وضبط المراجعات

اطلب فصل النطاق المؤكد والاستثناءات والافتراضات والخيارات والمعلومات الناقصة. حدّد مسؤوليات التوريد والتركيب والتشغيل والصيانة لكل واجهة. ثبّت مراجعة الرسومات المستخدمة للتسعير وأغلق المسائل المفتوحة قبل التصنيع. تغيير الفتحة أو القفل يستلزم مراجعة موثقة.

## أسئلة شائعة

**هل يمكن التسعير قبل المسح النهائي؟** نعم كتقدير مؤقت بافتراضات واضحة، مع تأكيد القياسات قبل التصنيع.

**هل العرض السعري موافقة فنية؟** لا؛ القرار التجاري والقبول الفني منفصلان.
