# CMS 个性化推荐 PRD

## 目标与边界

基于当前公开页面上下文提供可解释、可审计的内容或产品推荐。仅使用路径前缀、页面语言、桌面/手机和明确UTM来源，不创建用户画像，不读取联系人、询盘、cookie或敏感个人数据。

规则包含名称、优先级、匹配条件、标题、说明、内部目标路径和CTA。小优先级先匹配；只展示第一条已发布匹配规则，用户可关闭。没有命中、数据库异常或无发布规则时保持原页面，不显示占位内容。

## 工作流与验收

1. 编辑者保存规则仅生成草稿，官网不变化。
2. 提交后由不同审核发布人员发布；非超级管理员不能自审。
3. 数据库拒绝外部URL、非法路径、空标题和非法JSON。
4. 在路径、语言、设备、UTM四类条件逐项和组合验证命中；优先级最低数字胜出。
5. 未命中、RPC/网络失败和无规则时不渲染推荐卡。
6. 官网只能读取 `cms_published_recommendations`，不能读取草稿。
7. 390px与桌面端卡片不遮挡导航/询盘按钮，可键盘访问且可关闭。
8. 保存和发布写入审计日志，发布前后内容可追溯。

完成数据库迁移、真实规则发布和正式浏览器验收前不得标记上线。
