# CMS 审计日志中心 PRD

## 目标

为超级管理员和审核发布人员提供可检索、分页、查看详情和导出的不可变操作证据，替代账号页仅展示最近 50 条摘要的方式。

## 功能与安全

- 按邮箱/资源ID/元数据关键词、动作、资源类型、起止日期筛选。
- 每页50条，数据库限制单次最多200条；导出当前筛选页CSV，避免无界数据下载。
- 详情展示完整元数据JSON，不在前端推测或补写事件。
- 数据库函数仅允许超级管理员和审核发布角色读取；普通编辑、SEO、翻译、销售和只读均被拒绝。
- 审计表禁止更新和删除；新增记录仍只允许受控RPC或service-role服务。

## 验收流程

1. 超级管理员能访问列表并看到操作者邮箱、动作、资源和时间。
2. 审核发布角色可以只读访问；其他五类角色收到 `permission_denied`。
3. 组合关键词、日期、动作和资源筛选，结果与数据库原始记录一致。
4. 超过50条时可翻页，首尾按钮状态正确，总数不随分页变化。
5. 详情JSON与原始 `metadata` 完全一致。
6. CSV以UTF-8 BOM下载，含当前页所有字段，并正确转义逗号与双引号。
7. 直接尝试更新或删除日志时返回 `audit_logs_are_immutable`。

完成迁移、线上角色回归和浏览器下载验证前不得标记上线。
