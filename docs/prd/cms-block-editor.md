# CMS 区块编辑器 PRD 与验收

## 目标

用可排序、可隐藏、可编辑的结构化区块管理页面，而不是要求运营人员直接修改整段 JSON；桌面与手机预览保持与官网结构一致，图片可从受治理素材库替换。

## 区块模型

- 页面包含有序 `cms_page_sections`，区块存于 `cms_content_blocks`，每项具备稳定 ID、类型、排序、可见性和结构化内容。
- 支持文本、标题、按钮、图片、列表、产品/合作伙伴卡片等已注册类型；未知类型只读显示并禁止破坏性保存。
- 拖动排序必须有键盘上移/下移替代；隐藏不等于删除，删除需确认且可由版本历史恢复。
- 图片字段只引用受治理素材 ID/公开 URL；每张可编辑图片显示明确的编辑/替换图标。

## 保存与发布

- 区块编辑结果汇总为页面草稿，经 `cms_save_draft` 乐观锁保存并生成修订。
- 选择板块、文字编辑、图片替换和排序都不得直接改变 `published_content`。
- 页面预览读取当前草稿快照；发布仍经过异人审批流程。

## 验收流程

1. 新增、复制、隐藏、删除和拖动不同区块，刷新后顺序与状态保持。
2. 用鼠标拖动和键盘按钮分别排序，确认右侧板块位置立即响应且无误选。
3. 编辑首屏文案及逐张替换图片，确认每个可编辑元素入口明确、素材加载成功。
4. 在桌面和390px预览长标题、多图、RTL语言和隐藏区块，无横向溢出。
5. 并发保存触发版本冲突；预览正确但正式站保持不变，审批发布后才更新。
