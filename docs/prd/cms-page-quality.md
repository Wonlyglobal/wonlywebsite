# 页面质量检查 PRD 与验收

## 目标

对固定 WONLY 页面执行可追溯的 SEO、可访问性、链接、图片、性能和移动端检查；展示扫描服务真实证据，不根据字段是否存在虚构分数。

## 数据与安全

- `cms_quality_runs` 绑定页面 ID、固定 route 和内容版本，记录 queued/running/completed/failed、六类分数与错误。
- `cms_quality_issues` 保存类别、严重度、规则键、消息、CSS selector 和结构化证据。
- CMS 只发送 `run_id` 到自有扫描服务；服务端从数据库解析允许的固定页面和正式域名，禁止任意 URL。
- 扫描服务使用 service-role 回写运行和问题；浏览器无写权限。
- 没有完成回执时不显示分数；失败保留真实错误。

## 验收流程

1. 对首页、产品页、文章页各执行桌面和390px移动扫描，确认六类分数及证据来自真实页面。
2. 制造缺title、空alt、404链接、超大图片、横向溢出和性能退化，确认对应规则命中。
3. 修复并重新运行，保留前后两次记录且新分数/问题变化可核验。
4. 任意URL、未知run_id、浏览器直接回写和重复终态回写均被拒绝。
5. 服务未配置、超时、页面401/500、Lighthouse失败显示failed/unknown，不生成模拟分数。
6. 后台桌面和移动端查看100条运行、问题列表和长selector不溢出。
