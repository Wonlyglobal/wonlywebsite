# 全站搜索 PRD 与验收

## 目标

官网访客可检索已发布的产品、解决方案、页面和文章；后台可查看索引覆盖并按六种语言验证结果。任何草稿、待审核或未发布译文不得进入搜索。

## 数据契约

- `cms_search_site(query, locale, limit)` 为只读公开 RPC；关键词 2–100 字符，单次最多 20 条。
- 数据源仅限 `cms_pages.status='published'` 且存在 `published_content` 的记录。
- 支持 en/ar/fr/ru/es/pt；非英文优先使用已发布内容内翻译，再使用已保存翻译，最终回退英文。
- 返回页面键、标题、本地化路由、页面类型、摘要、相关度和更新时间，不返回原始草稿 JSON。
- 使用 PostgreSQL GIN 全文索引与 `websearch_to_tsquery`；不接收 SQL、任意表名或排序表达式。

## 验收流程

1. 后台核对可索引数与缺正式内容数，分别用产品、应用和技术词测试六语。
2. 创建仅草稿页面和未批准译文，确认搜索结果中不存在。
3. 官网 `/search?q=security%20door` 验证结果、摘要和路由；空结果显示联系入口。
4. 验证1字符、超过100字符、未知语言被拒绝；特殊字符不能造成SQL错误或注入。
5. 桌面及390px移动端验证输入框、结果列表和无结果状态无溢出。
6. 发布/撤回内容后验证索引即时一致；生产查询失败时显示真实不可用状态，不展示模拟结果。
