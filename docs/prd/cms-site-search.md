# 全站搜索 PRD 与验收

## 目标

官网访客可检索已发布的产品、解决方案、页面和文章，并通过输入建议与热门内容发现更多页面；后台可查看索引覆盖、热门词、无结果词、结果点击率和热门内容，并按六种语言验证结果。任何草稿、待审核或未发布译文不得进入搜索。

## 数据契约

- `cms_search_site(query, locale, limit)` 为只读公开 RPC；关键词 2–100 字符，单次最多 20 条。
- 数据源仅限 `cms_pages.status='published'` 且存在 `published_content` 的记录。
- 支持 en/ar/fr/ru/es/pt；非英文优先使用已发布内容内翻译，再使用已保存翻译，最终回退英文。
- 返回页面键、标题、本地化路由、页面类型、摘要、相关度和更新时间，不返回原始草稿 JSON。
- 使用 PostgreSQL GIN 全文索引与 `websearch_to_tsquery`；不接收 SQL、任意表名或排序表达式。
- `cms_search_discover` 返回搜索ID、真实结果和结果数；`cms_record_search_click`只接受24小时内的搜索ID、已发布页面键和1–20位结果位置。
- `cms_search_suggestions`只从已发布页面标题和内部路径生成建议；`cms_popular_content`按最近30天真实点击排序，无点击时按最近更新内容安全回退。
- `cms_search_discovery_dashboard`仅认证后台角色可读取，提供7/30/90/180天汇总、热门词、无结果词及热门内容。
- 搜索分析不保存IP、Cookie、会话身份或用户账号。疑似邮箱和电话号码统一存为`[redacted sensitive query]`，且不进入后台关键词榜单。
- 搜索事件与点击表不向匿名或普通认证用户开放直接读写，只能通过字段固定的安全函数记录。

## 验收流程

1. 后台核对可索引数与缺正式内容数，分别用产品、应用和技术词测试六语。
2. 创建仅草稿页面和未批准译文，确认搜索结果中不存在。
3. 官网 `/search?q=security%20door` 验证结果、摘要和路由；空结果显示联系入口。
4. 验证1字符、超过100字符、未知语言被拒绝；特殊字符不能造成SQL错误或注入。
5. 桌面及390px移动端验证输入框、结果列表和无结果状态无溢出。
6. 发布/撤回内容后验证索引即时一致；生产查询失败时显示真实不可用状态，不展示模拟结果。
7. 输入两个字符后验证建议列表仅包含正式页面；清空查询时展示热门内容，桌面键盘和390px触控均可进入目标页。
8. 搜索并点击第1、3位结果，确认后台搜索数、点击数、点击率、页面及平均位置正确；重复点击同一结果不重复计数。
9. 搜索不存在的正常产品词，确认进入无结果词；输入邮箱和电话号码，确认后台只增加脱敏计数且不出现原文。
10. 以匿名身份直接读取或写入`cms_search_events/cms_search_clicks`应被RLS拒绝；伪造过期搜索ID、草稿页面键和21位位置均被拒绝。
