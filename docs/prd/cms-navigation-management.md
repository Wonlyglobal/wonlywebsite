# 菜单可视化管理 PRD 与验收

## 目标

用直观的三级树替代平铺输入框：明确显示 L1/L2/L3、缩进和连接线，可新增子项、隐藏、删除、同级拖拽/上下排序，并在发布前查看桌面结构预览。

## 数据与权限

- `cms_navigation` 保存主导航草稿树、正式树、版本和发布人；最多三级，每层最多30项。
- 每项包含稳定 ID、标签、URL、隐藏状态和 children。URL 可为空（父菜单）或站内路径/HTTPS。
- Editor 保存草稿，Reviewer 异人发布；保存后官网不变。
- `cms_published_navigation` 只公开正式树。官网优先读取正式树，接口失败时回退代码内导航。
- 保存和发布写入审计；版本冲突整体拒绝。

## 验收流程

1. 自动生成现有官网完整菜单并逐项核对标签、URL、顺序和三层父子关系。
2. 新增一级/二级/三级，验证层级标识、缩进、连接线及桌面预览。
3. 同级拖拽、上下移动、隐藏和删除；跨层误拖不应破坏树。
4. 测试第四级、非法URL、空标签、超量和旧版本保存，数据库均拒绝。
5. 保存草稿后官网不变；另一 Reviewer 发布后桌面和手机导航同步，隐藏项不出现。
6. 键盘、窄屏及长标签无溢出；外链安全属性和站内语言路径正确。
