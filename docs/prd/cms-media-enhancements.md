# 媒体资产增强 PRD 与验收

## 目标

媒体库支持直接上传、预览、搜索、类型筛选、分页、Alt/标签编辑、归档、坏图提示和就地替换。每张卡片左下角提供替换图标。

## 数据和替换规则

- `cms_assets` 增加 Alt、标签、状态、替换关系和更新时间。
- 允许格式：JPEG、PNG、WebP、AVIF、GIF、SVG；单文件不超过 10MB。
- 替换会上传新对象和新资产记录，将旧资产标记 `replaced`，仅替换页面草稿及翻译草稿中的旧 URL，并让相关页面回到草稿、版本递增。
- 已发布内容不会被静默改写；重新审批发布后新图才上线。
- 保留旧存储对象，避免已发布页面或历史版本立即断图；后续清理必须先做引用检查。

## 验收流程

1. 上传六种允许格式及超限/非法文件，确认允许项入库、非法项被拒绝。
2. 搜索文件名、Alt、标签，按类型筛选并翻页；移动端无横向溢出。
3. 点击缩略图打开大图；网络失败显示坏图提示，不留空白卡片。
4. 点击每张卡片左下角铅笔图标替换，确认生成新资产、旧资产变为 replaced、引用该 URL 的草稿被更新、正式内容未变。
5. 编辑 Alt/标签并刷新，确认保存；归档后默认列表隐藏。
6. Viewer/SEO/Translator 不可上传、替换或归档；Editor/Super admin 可操作，审计日志包含替换与元数据更新。
