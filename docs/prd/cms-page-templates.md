# CMS 页面模板库 PRD

## 目标

管理员可把现有页面草稿保存为命名模板，并将模板应用到其他页面作为新草稿。模板不包含发布权限，不允许直接改变线上内容。

## 权限与数据

- `editor`、`super_admin` 可创建、应用和停用模板；其他角色只读。
- `cms_page_templates` 保存名称、说明、适用页面类型、模板快照、创建人和启用状态。
- 创建模板必须来自现有页面草稿；应用时要求目标页面版本一致，防止覆盖他人修改。
- 应用后目标页面 `content_version + 1`、状态回到 `draft`，旧审批与待执行排期失效，并写版本和审计记录。

## 验收

1. 无编辑权限角色只能查看。
2. 从页面创建模板后列表即时可见，快照与源草稿一致。
3. 应用模板遇到版本冲突时拒绝覆盖。
4. 应用成功后只更新草稿、增加版本，不改变 `published_content`。
5. 旧审批和待执行排期失效，审计记录完整。
6. 停用模板不能再应用，但历史记录保留。
