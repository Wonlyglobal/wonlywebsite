# WONLY SEO 快速排名执行方案

更新日期：2026-09-18

## 目标与边界

目标是在不使用批量低质内容、购买垃圾外链或虚构认证的前提下，优先推动已经具备产品和工程证据的商业关键词进入可见排名。排名由搜索引擎决定，不承诺固定天数；以 Google Search Console 的非品牌曝光、平均排名、有效索引页和询盘路径作为验收数据。

## 第一优先级：商业意图页面（0–14 天）

- 已有核心页：Security Door Manufacturer、Smart Door Manufacturer、Smart Lock OEM/ODM、Fire-Rated、Acoustic/STC、Coastal。
- 本轮新增：Commercial Steel Security Doors，独立承接 commercial steel security doors、commercial security doors、steel security doors for buildings，避免与 manufacturer 页面争抢同一搜索意图。
- 每页必须具备独立 title、description、canonical、H1、FAQ、Breadcrumb、静态 HTML、证据清单、明确 RFQ 输入和可追踪 CTA。
- 每个目标页获得至少 3 个上下文内链，其中至少 1 个来自产品类目页、2 个来自已发布技术或采购内容。

## 第二优先级：接近前十查询冲刺（每周）

Search Console 接通后，每周筛选过去 28 天：曝光不少于 20、平均排名 8–25、与商业目标一致的查询。每次只处理 3–5 个机会词：

1. 确认查询应由现有页面承接，避免新建近义页面造成关键词内耗。
2. 补齐首屏答案、规格表、证据边界、FAQ 和相关实体词。
3. 从 2–4 篇已索引内容增加自然上下文内链。
4. 更新 sitemap lastmod，并在 GSC 请求重新抓取重点 URL。
5. 14 天后比较曝光、排名、CTR；无增长则检查搜索意图或合并页面，不持续堆字数。

## 第三优先级：主题集群（2–6 周）

- 每周发布 3–5 篇原创工程内容，单日不超过 1 篇。
- 优先围绕已上线商业页补充：commercial door hardware matrix、steel door frame and wall interface、panic hardware and access control、fire/security evidence matrix、coastal finish maintenance、STC field acceptance。
- 每篇文章连接 1 个商业落地页、1 个产品页和 1–2 篇同主题文章；封面保持唯一。
- 文章必须有可验证的工程信息和适用边界，不扩写未经证明的认证、测试值、MOQ 或交付数字。

## 第四优先级：权威与外链（持续）

- 优先获取经销商、项目案例、行业协会、展会、供应商名录和真实合作伙伴页面的品牌或产品链接。
- 每周准备 2–3 个高相关外联机会；未经负责人确认不自动发送。
- 禁止购买站群链接、批量目录提交、评论区链接和 AI 拼接客座文章。

## 数据看板与验收

- 每周：非品牌查询曝光、点击、CTR、平均排名，8–25 位机会词数量，目标页索引状态。
- 每两周：目标页进入前 10 / 前 20 的查询数、自然搜索到 CTA 点击与表单打开的路径。
- 每月：自然询盘数、有效询盘率、商业页转化率、获得的有效引用域。
